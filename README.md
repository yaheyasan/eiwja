Relucent

Relucent is a flashcard app for learning and reviewing vocabulary.

You can study with flashcards, practise by typing or listening, work with words in sentences, and test yourself with quizzes.

Study modes

- Flashcards
- Typing practice
- Listening practice
- Sentence practice
- Tests and exams

The goal is to make studying simple: open the app, review a few words, and keep making progress.

Project

Relucent is an ongoing project. More improvements and features will be added over time.
